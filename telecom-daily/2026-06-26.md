## 今日焦点：MWC Shanghai 2026 + China Telecom 联手把 6G 从"通信管道"重定义为"通感算存 AI 联合编排"

### 1. 事件概述

2026 年 6 月 24-25 日，MWC Shanghai 2026 开幕当日，GSMA 在主旨演讲中正式把移动产业带入"IQ era"叙事，并联合中国移动、中国电信、中国联通三家中国运营商集体站台；次日（6 月 25 日）中国电信首席技术专家 Yue Wang 在 RCRTech Telco AI Forum 上明确表态：**AI-native 6G 必须从底层架构重构，把通信、计算、存储、AI 资源联合编排**，现有"确定性架构 + 预定义接口 + 规则引擎 + 人工控制"的电信网络无法承载未来 AI 服务。

两件事叠加不是巧合，而是中国通信产业一次有预谋的**话语权行动**——GSMA 给出时代叙事（IQ era），中国运营商给出技术路线（AI-native + 通感算存编排），华为、中兴等设备商在展台上提供产品化承接。

### 2. 行业格局影响

**设备商**：从"卖管道"变成"卖 AI 内核"。华为、中兴、爱立信、诺基亚的竞争维度被拉到了 AI-native 核心网、算力底座、网络 API 三个新轴上。Telefónica + Nokia 已经把 MCP/A2A（Model Context Protocol / Agent-to-Agent）协议接入 SIM-swap、device-swap API，做成 AI agent 自动调用网络能力防欺诈的 PoC——这意味着设备商如果不能在 AI-native 核心网 + 网络 API 化两条战线同时投入，将被锁死在传统 RAN 集采的边际利润里。

**运营商**：三家中国运营商不再是配角，而是 IQ era 的"主推手"。中国移动董事长陈忠岳、中国电信首席专家王悦、中国联通集体站台——这是历史上第一次 GSMA 把"未来网络架构"的话语权主动交给中国运营商。原因很现实：海外运营商在 5G 商业化上被 OTT 反复挤压（"dumb pipe"困境），而中国运营商靠着 5G-A + AI 场景化运营拿到了 10M+ 5G-A 用户、330+ 城市覆盖的全球领先样本，GSMA 需要这个故事。

**芯片商**：被夹在中间。NVIDIA 在 2026 State of AI in Telecommunications 报告里反复强调 GPU 在网络 AI 推理中的位置，但"通感算存联合编排"的提法本质上是把云端算力调度权往电信网络内部切走一块——这对云厂商（AWS、Azure、阿里云）是直接威胁，对 NVIDIA 的推理算力销售也是结构性变化（从纯云端推理变为"云 + 边缘 + 网络内"分布式推理）。

**云厂商**：最危险的受害者。如果 6G 时代电信网络自带算力调度接口，企业级 AI 推理不再需要绕道公有云，AWS / Azure / GCP 的"网络 + 算力"双轮叙事会出现缺口。中国电信此次强调"network + cloud infrastructure 整合 + 组织变革"，信号是：电信运营商要自建云并把 AI 推理放在自己的网络里。

### 3. 技术 / 商业含义

**技术含义**：
- 6G 不再是 5G 的演进，是**架构重构**。中国电信的三层模型（基础设施层 / 运营层 / 服务层）实际上是把 IaaS / PaaS / SaaS 的云原生分层思路移植到了电信网络，每个层都引入 AI 编排。
- "AI services will not only ask for connectivity, but also for compute, latency, adaptation"——这是用云原生语言重写电信 SLA，未来 SLA 不再只是带宽/时延，而是"算力 + 时延 + 模型版本"的复合契约。
- 王悦明确指出 NTN（非地面网络）和 U6GHz 是 6G 时代两大新容量来源，并强调"agentic AI 需要 AI-native 核心网"——这意味着核心网从"信令转发"变成"AI agent 编排平台"，是 3GPP 标准制定层面的话语权之争。

**商业含义**：
- GSMA Open Gateway 网络 API（86 个运营商集团、300+ 网络、覆盖 80% 全球移动连接）已经从概念阶段进入商业化阶段，60% 企业预测 2026 年底前部署网络驱动的 AI 解决方案。这意味着电信运营商第一次有了一个**可对外变现的 AI 入口**。
- "Agentic networks + MCP/A2A" 是 2026 年的拐点：AI agent 开始通过 MCP 协议自主调用网络 API，运营商要么进入 agent 经济，要么被绕开。这是"中间地带消失"的关键年。
- 中国 2030 年移动技术对 GDP 贡献预期达 $2.1 万亿（2025 年 $1.5 万亿），增量中 AI 驱动场景占主导——工信部总工程师张志红提出的"双万兆网络 + AI + 6G"是中国版基础设施投资路线图。

### 4. 对从业者的启示

如果你是**通信设备商技术 / 产品负责人**：
- **立即评估**自己的产品线能否拆解成"AI-native 核心网 + 算力底座 + 网络 API"三个独立产品组合。MWC Shanghai 上仍只讲 RAN 性能的厂商会被归类为"传统管道商"。
- **追踪标准**：3GPP Release 19/20 的 AI-native 网络相关 Study Item 进展，特别是 ITU-T Y.3170 系列架构框架。Yue Wang 提出的三层模型大概率会成为中国 6G 提案的参考模板。
- **建立 MCP/A2A 适配能力**：未来 18 个月内，没有 MCP 接口的网络 API 等同于没有 API。Telefónica-Nokia 的 PoC 已经验证技术可行性，跟进 PoC 不能晚于 2026 Q4。

如果你是**运营商网络规划 / 运维人员**：
- **重新设计 SLA 指标体系**：在传统 KPI（接入成功率、掉线率、时延）之外，开始定义"算力 SLA"——单位面积可调度算力、模型推理时延、推理精度。
- **关注"AI 场景化运营"落地**：China Mobile EVP 李慧棣在 DTW 2026 主题演讲已经把 Autonomous Networks 推到 L4/L5。建议运维团队开始建立 AI 异常检测闭环，至少在无线侧做 PoC。
- **关注 U6GHz 频谱**：MIIT 已经表态要加速 U6GHz 规划，规划部门需要从现在开始做清频、干扰共存、设备路标的预研。

如果你是**AI / 云解决方案架构师**：
- **重新评估客户对接路径**：未来大型企业客户的 AI 推理需求可能不再全部走公有云，而是通过运营商网络 API 调度本地 + 边缘算力。运营商合作伙伴关系要从"流量批发"升级到"算力联合销售"。
- **关注 GSMA Open Gateway 的 API 清单**：SIM swap、Number Verification、Quality on Demand、Device Location 已经在金融、防欺诈、物流、医疗商用——这是 agent 经济的基础设施，比 OpenAI 的 GPT Store 更早实现商业化。

**最关键的一条**：2026 年是电信产业 AI 化的"分水岭年"。从今天开始，所有关于 6G 的讨论都必须包含 AI-native 这一条主线；任何只讲 RAN、只讲带宽的技术路线图都已经过时。

## 简讯

**1. Ericsson 与 Telia 联手在瑞典建 5G/6G/AI 测试中心**
Ericsson、Telia 宣布在瑞典共建测试中心，覆盖 5G 演进、6G 关键技术和 AI 网络应用三个方向。这是北欧运营商第一次明确把"AI in network"作为 6G 试验的独立维度，与中国电信的 AI-native 6G 思路形成跨大西洋共振。**意义**：6G 不再只是东亚 + 北美的双极叙事，欧洲在 AI-native 6G 上没有掉队，3GPP 标准博弈将更复杂。Ericsson 也借此向外界证明其在 AI 网络方向不是被动跟随者。

**2. 中国 5G-A 用户突破 1000 万，覆盖 330+ 城市**
GSMA 在 MWC Shanghai 2026 上披露最新数据，中国 5G-A 商用用户已超 1000 万，覆盖城市从年初 200+ 扩展到 330+。**意义**：5G-A 不再是"试商用阶段"，而是中国运营商在 6G 到来前的关键现金流和场景验证载体。工信部"双万兆"升级路线图（10G PON + 5G-A）意味着设备集采订单会在 2026 H2 - 2027 H1 密集落地，对华为、中兴、爱立信、诺基亚的 5G-A 产品线订单能见度是确定性利好。

**3. NSW 政府追加 $2.09 亿投资 P25 公共安全网络**
澳大利亚新南威尔士州政府再投 $2.09 亿升级 P25 公共安全专网。**意义**：在主流运营商忙着搞 AI-native 6G 的同时，关键任务专网（Mission Critical Networks）的稳定现金流仍在延续。Hytera、Motorola Solutions、海能达在这一市场的份额会进一步巩固，与公网运营商的"AI 军备竞赛"形成对照——专网市场的护城河是合规、可靠性、长生命周期，不是技术先进性。

**4. RCR Wireless 发表"Dumb pipes no more"署名文章，系统论证电信 AI 商业机会**
Zenith System Solutions CTO Neeraj Kumar 在 RCR Wireless 发表长文，引用 McKinsey、IDC、Ericsson、ABI、IBM、NTT Data、JPMorgan、WEF、NVIDIA、Juniper 等 10+ 份 2026 年报告，系统论证电信运营商不再是 dumb pipe，而是 AI 时代的 programmable 平台。**意义**：这是行业话语层面的"集体造势"——单一报告不足信，但 10 份独立报告同向，意味着企业 CIO 层面的认知正在转变，运营商 AI 商业化的客户教育成本在快速下降。

## 信号追踪

**信号 1：AI-native 6G 架构标准博弈进入"提案提交期"**
- **信号内容**：China Telecom 首席技术专家 Yue Wang 在 Telco AI Forum 提出的"基础设施 / 运营 / 服务"三层 AI-native 架构模型，以及对 NTN、U6GHz、AI-native 核心网的明确诉求，是中国 6G 提案的雏形。同时 Ericsson-Telia 瑞典测试中心也把 AI as first-class citizen 加入 6G 试验维度。
- **为什么值得追踪**：3GPP Release 20 / ITU-T IMT-2030 框架将在 2026 Q4 - 2027 Q1 进入实质性技术提案阶段。哪一方先提交完整的 AI-native 架构参考模型（不只是 feature list），就能主导后续标准讨论。
- **追踪窗口期**：2026 Q3 - 2027 Q2。**关注节点**：3GPP TSG SA 会议（每 3 个月一次）、ITU-T Focus Group on AI-Native Networks 系列白皮书。

**信号 2：网络 API + MCP/A2A 协议栈决定运营商在 Agent 经济中的位置**
- **信号内容**：GSMA Open Gateway 已覆盖 86 个运营商集团、300+ 网络、80% 全球移动连接，但 Telefónica-Nokia 用 MCP 协议把 SIM-swap/device-swap API 接入 AI agent 防欺诈流程是 PoC 阶段。GSMA 在 MWC 2026 巴塞罗那已明确："如果网络 API 不是 MCP-accessible，AI agents 会绕过它们。"
- **为什么值得追踪**：这是"中间地带消失"的拐点——运营商要么成为 agent 经济的基础设施，要么被 hyperscaler + 设备商联合方案替代。2026 年底前 MCP 接入网络 API 的运营商数量是先行指标。
- **追踪窗口期**：2026 H2 - 2027 H1。**关注节点**：GSMA Open Gateway 季度报告、Telefónica / Vodafone / 中国移动的 MCP 试点公告、Nokia Network as Code 平台迭代。

**信号 3：中国运营商"双万兆 + AI + 6G"基础设施投资周期启动**
- **信号内容**：工信部总工程师张志红在 MWC Shanghai 2026 明确"双千兆向双万兆网络演进" + "6G 标准研发加速" + "大模型与农业、教育、医疗深度融合"。GSMA 预测中国 2030 年移动技术 GDP 贡献 $2.1 万亿。
- **为什么值得追踪**：这是中国版基础设施投资路线图的官方定调，意味着 2026 H2 - 2028 年中国电信运营商 CAPEX 重心将向"10G PON + 5G-A 深化 + 算力网络 + 6G 预研"四线并举倾斜。华为、中兴、新华三、烽火的订单能见度与这条主线强相关。
- **追踪窗口期**：2026 H2 - 2027 全年。**关注节点**：三大运营商年度 CAPEX 指引（2027 年指引通常在 2026 Q4 发布）、工信部"双万兆"专项行动政策、CCSA（中国通信标准化协会）TC610 6G 评估组输出。
