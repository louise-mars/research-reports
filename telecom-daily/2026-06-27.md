# 通信行业日报｜2026-06-27（周六）

> **今日焦点一句话**：MWC Shanghai 2026 把行业主旋律从"5G-A 落地"切换到了"AI Native 网络 + Token 计费"——中国运营商和华为正在联手把电信运营商从"管道商"重新定义为"AI 推理算力网关"，这是十年一次的赛道迁移。

---

## 今日焦点（深度分析）

### 1. 事件概述

MWC Shanghai 2026 于 6 月 24 日（周三）开幕，本周三大运营商（China Mobile/China Telecom/China Unicom）和华为密集释放关键信号：
- **China Mobile EVP 李慧镝**（DTW 2026 演讲）：提出"AI Native 网络 + 数字孪生 + 多智能体协同 + 算力网络融合"四要素自治网络体系，21 个高价值场景已实现 L4 自治，三年内扩展到 38 个。
- **China Telecom 首席技术专家王跃**（6/25）：AI-native 6G 必须实现"网络与算力的联合编排"，这是架构层面的根本转变。
- **华为轮值董事长 David Wang**（MWC Shanghai 主题演讲）：联合国内三大运营商发布"5G-A 高上行 + 体验变现 + AI 业务升级 + **Token 变现**"四大方案，正式把"Token 计费"作为新的商业模式。
- **GSMA 总干事 Vivek Badrinath** 在开幕演讲中重提"**IQ era**"（智能体时代）愿景，明确 AI 智能体将通过 MCP/A2A 协议自主调用网络 API。

事件定性：这不是 MWC 的常规主题演讲，而是中国通信产业第一次**集体性地给电信运营商换了一个身份标签**——从"比特搬运工"变成"AI 推理算力的守门人"。

### 2. 行业格局影响

**竞争坐标正在被重画**：

- **设备商层面**：华为是这次叙事的主导者。它把"AI-ON（AI-Optical Network）"白盒硬件 + Ascend A3 SuperPoD + OceanStor A800 打包成"Token 计费"的基础设施栈。值得警惕的是——**Token 变现几乎不可能在 Five Eyes 市场（美/英/澳/加/新）落地**，因为华为被禁。这本质上是华为在"中国+中东+非洲"市场的**区域锁定战略**，用商业模式绑定把运营商锁进华为硬件生态。
- **运营商层面**：China Mobile 和 China Telecom 不再是"被动提供 5G-A 通道"的角色，而是**主动重构 AI 价值链的入口方**。李慧镝提到的"从效率提升到价值创造"翻译过来就是：别再卷 ARPU 了，要卷 AI 推理单价。
- **西方阵营的应对**：Ericsson + Telia 在瑞典建 5G/6G/AI 测试中心（6/22 消息），Nokia + AWS + Databricks 联合扩展 telco AI 控制层（本周 RCR Wireless）——欧洲设备商选择"通用云 + 网络 AI 编排"的路线，本质上是绕开华为的"全栈锁定"。
- **超大规模云厂商**：AWS、Azure、Google Cloud 面临一个结构性威胁——如果运营商真的把"Token 变现"做成了，AI 平台就**无法绕过运营商直接采购带宽**，必须从运营商的 API 网关进入。这正是 GSMA 警告的："AI agents will route around you, or you are in the flow. No middle ground."

**位置移动图**：
- 华为：从"5G 设备商" → "AI 算力 + 网络全栈供应商"
- 中国三大运营商：从"流量管道" → "AI 推理分发节点"
- Ericsson/Nokia：从"无线设备商" → "云原生 AI 网络编排伙伴"
- 西方超大规模云：从"AI 基础设施默认入口" → "被迫接受运营商 API 中间层"

### 3. 技术/商业含义

**技术含义**：
- "AI Native 网络"≠ "在网络上跑 AI 模型"。它的真正含义是**网络设备本身（基站、核心网、宽带接入、光传输）原生嵌入 AI 能力**，而不是外挂 AI 优化器。这意味着下一代 RAN 和核心网的设计规范会被改写——芯片架构（基带+推理 NPU）、OAM 协议、QoS 模型都要重做。
- "网络-算力联合编排"是 6G 的核心架构命题（不再是 5G 时代的"网络 + 算力叠加"），背后是通信产业在赌 6G 标准的话语权。
- "Token 计费"的工程挑战：需要**深度参与推理上下文**（prompt 长度、模型类型、推理优先级），传统的"按字节计费"CDR 系统完全不适用。运营商需要建设新的计费/结算/BSS 系统，这是一笔巨大的 IT 投资。

**商业含义**：
- 这是通信行业**第一次出现"非流量"的规模化收入模型**。如果 Token 计费跑通，运营商的天花板从"人口数 × ARPU"变成"AI 推理调用次数 × 单价"——理论上市场可以比传统电信大 10-100 倍。
- 风险：Token 计费的真实需求存在吗？目前主要是 ToB 场景（金融、政务、制造），C 端还没有成熟的 Agentic 应用拉动。"鸡和蛋"问题——没有杀手级 Agent 应用，Token 计费就是 PPT。
- 区域分化：华为系方案绑定中/非/中东市场，西方运营商会被迫选择 Ericsson/Nokia + AWS/Azure 的组合，行业会**事实分裂成两套生态**。

### 4. 对从业者的启示

**对通信从业者的具体可执行启示**：

1. **重新定位你的技术栈价值**。如果你还在做"传统 RAN 优化、传输规划、核心网调测"，需要尽快**横向扩展到 AI Native 网络方向**。建议关注：3GPP Release 19/20 关于 AI/ML for RAN 的研究项目、ITU-T IMT-2030（6G）的网络智能管理框架。具体可以读华为刚发布的 AI-ON 10 个白皮书，对照看下你手头项目哪些能套用。

2. **关注 BSS/OSS 改造机会**。Token 计费落地最大的拦路虎不是 RAN，而是 BSS（计费系统）。中国移动各省公司、华为/中兴的 BSS 部门未来 12-18 个月会密集招人做 AI-aware 计费引擎设计。如果你做 IT/数据/计费系统集成，这是一次结构性机会。

3. **警惕"叙事大于实际"的风险**。MWC 主题演讲从来都讲愿景。看实际进展要看：①华为有没有公布具体商用合同（不只是 POC）；②中国电信有没有公布 token 收入的第一笔真实入账；③有没有第三方 Agent 应用调用运营商 API 的实测数据。**在 6 个月内如果没有真实商用案例，"Token 计费"就是新一轮炒作**。

4. **对海外市场从业者**：Ericsson + Telia 的瑞典测试中心值得盯。这是欧洲阵营对"AI Native"叙事的回应，看他们会不会提出**不依赖华为硬件的替代路径**。如果你是做海外市场的，这是判断未来 5 年设备选型策略的关键信号。

5. **个人学习方向**：建议这周把 MWC Shanghai 2026 华为、China Mobile、China Telecom 三场主题演讲的 PPT/视频过一遍。聚焦"AI Native 网络架构"和"Token 变现"两个关键词——这是 2026 年下半年的两个核心叙事，所有客户对话都会围绕这两个词展开。

## 简讯

**① 中国 MIIT 副部长重申 6G 标准研发加速，"双万兆"网络提上日程**
- 工信部总工程师**钟志红**在 MWC Shanghai 开幕主题演讲中表示，中国将持续推进下一代数字基础设施部署，加快 6G 标准研发；同时推动**"双千兆"向"双万兆"网络演进**。
- **为什么重要**：政策层面定调 6G 是"十四五"末到"十五五"的核心任务。"双万兆"对设备商意味着新一轮光网络/FTTR/5G-A 高频扩容订单，对从业者意味着 2027-2028 年会有密集的 6G 外场测试机会。

**② 华为发布 AI-ON 全光网络 10 大产品，剑指"AI 时代全光目标网"**
- 华为在 MWC Shanghai AI-ON Summit（6/25）发布 AI-FAN 和 AI-OTN 产品系列，目标是帮运营商构建"AI 中心化全光目标网"，实现"价值驱动的超千兆/10Gbps 运营"，提供"高质量算力接入和使用"。
- **为什么重要**：华为把光网络产品线**全面 AI 化**——这意味着传统光通信厂商（中兴、烽火、Ciena、Infinera）面临"AI 不 AI"的产品代差竞争。值得关注的反差是：Ciena 同期在强调"AI demands multiple optical architectures"，但产品节奏明显落后于华为。

**③ GSMA：全球移动产业 2030 年将为中国经济贡献 2.1 万亿美元**
- GSMA 在 MWC Shanghai 发布最新报告，指出到 2030 年移动技术（5G、物联网、AI）将为中国经济累计贡献 **2.1 万亿美元**。报告强调 5G、物联网和 AI 在推动行业数字化转型、支持经济韧性方面的关键作用。
- **为什么重要**：这是给"中国通信产业长期增长空间"打底的官方数据。1.2 万亿移动产业 + 5G-A + 6G 演进 + AI 融合，中国通信市场 5 年内不会出现天花板。对投资视角（通信 ETF/运营商股票）有支撑作用。

**④ Ericsson + Telia 在瑞典建 5G/6G/AI 测试中心，欧洲阵营的"AI Native"回应**
- Ericsson 与 Telia 宣布在瑞典共建测试中心，覆盖 5G、6G 和 AI 三个方向。这是欧洲主流运营商和设备商对"AI Native"叙事的实质性回应。
- **为什么重要**：在欧洲市场，Ericsson + Nokia + AWS 是相对确定的技术路线。**对中国设备商出海而言，这是个警示信号——欧洲不会接受华为"全栈 Token 变现"模式**，会走"通用云 + 网络编排"的开放路线。如果你的业务涉及海外设备准入，这是判断市场策略的关键案例。

## 信号追踪（持续关注线索）

### 信号 ①：Token 计费的真实商用进展
- **信号内容**：华为联合 China Mobile Hubei 验证"AI 推理加速方案"（OceanStor A800 + Ascend A3 SuperPoD + Unified Cache Manager），长序列推理（代码生成、多轮对话）Token 吞吐量提升 372%。但目前没有公开商用收入数据。
- **为什么值得追踪**：Token 计费是这次 MWC Shanghai 抛出的**最具颠覆性的商业模式命题**，但"鸡和蛋"问题严重——没有真实 Agent 应用拉动就是 PPT。**追踪它的真实性是判断 2027 年通信行业走势的关键变量**。
- **追踪窗口期**：6-12 个月。关键观察点：①华为/中国移动是否公布第一个 token 计费商用合同；②是否有第三方 Agent 应用（如金融客服、智能制造）公开表示通过运营商 API 调用推理算力；③中国电信/移动的季报中是否出现"AI 算力收入"分项。
- **追踪来源**：华为官网新闻、RCR Wireless 中国运营商季报、China Mobile Hubei 公开招标信息。

### 信号 ②：中国 6G 标准研发节奏与"双万兆"网络落地
- **信号内容**：MIIT 官员在 MWC Shanghai 重申 6G 标准研发加速，"双千兆"向"双万兆"演进。这是政策层面的明确信号。
- **为什么值得追踪**：6G 标准话语权决定了未来 10 年全球通信产业链格局。中国这次明确表态加速研发，意味着 ITU/3GPP 关于 6G 的关键议题（AI Native、网络-算力融合、空天地海一体化）会持续被推到国际舞台。
- **追踪窗口期**：12-18 个月（到 2027 年中）。关键观察点：①中国向 ITU 提交的 6G 愿景文档；②6G 试验网牌照发放时间；③运营商 10G PON/FTTR 集采规模和节奏。
- **追踪来源**：MIIT 官网、CAICT 报告、运营商集采公告、ITU-R IMT-2030 工作组进展。

### 信号 ③：欧洲阵营"通用云 + 网络 AI 编排"路线的实质性进展
- **信号内容**：Ericsson + Telia 瑞典测试中心、Nokia + AWS + Databricks telco AI 控制层扩展、Orange 强调 AI 信任。欧洲设备商和运营商集体选择**避开华为全栈锁定**的开放路线。
- **为什么值得追踪**：通信行业可能会**事实分裂成两套生态**——中国/中东/非洲走华为系，欧洲/北美走 Ericsson/Nokia+云厂商路线。这对设备商战略、运营商采购、芯片厂商布局都有深远影响。
- **追踪窗口期**：6-12 个月。关键观察点：①GSMA Open Gateway 倡议的实际 API 调用量；②Ericsson Telia 测试中心第一个公开 Demo；③AWS/Azure 是否有"Telco AI Control Layer"的正式产品发布（目前看还是合作方案）。
- **追踪来源**：Light Reading、TM Forum 报告、Ericsson/Nokia 官方公告、AWS/Azure telco 行业博客。
