## 今日焦点：MWC Shanghai 2026 三大共识落地——通信业的"比特+Token"新计量时代

### 1. 事件概述

6月24日开幕的 MWC Shanghai 2026 上，**GSMA、中国三大运营商、华为、Ericsson 在不同场合共同发出了同一组信号**：移动通信产业正式进入"IQ Era"（智能体时代），网络的计量单位从单纯的"比特"扩展为"比特+Token"，6G 架构必须原生 AI，三大运营商要在 2030 年前共同撑起一个 2.1 万亿美元的中国数字经济底座。这不是单家公司的发布会，而是一次**全行业的范式共振**——上一次看到这种密度的一致表态，还是 2019 年 5G 商用前夜。

### 2. 行业格局影响

**设备商层面：华为抢跑"E2E Token 货币化"叙事**
华为轮值董事长 David Wang 在 MWC Shanghai 发布"AICentric 目标网络"，与三大运营商联合推出 **5G-A 高上行、体验货币化、AI 业务升级、Token 货币化** 四个解决方案包。这是华为第一次把"Token"作为独立的计费/计量维度写入 ToB 解决方案——意味着设备商已经从"卖连接"转向"卖算力调度+智能体承载"。Ericsson 同期在瑞典投入 3 亿瑞典克朗（约 2900 万美元）建"Digital Arena Sweden"国家 5G/6G/AI 测试中心，由 Telia 落地，意图在欧洲侧夺回"主权 AI 算力"叙事。**两家巨头不再比谁的基站多，而是比谁更接近 AI 算力调度权。**

**运营商层面：中国移动 EVP 李慧镝（Li Huidi）在 DTW2026 提出"连接意图到结果"（intent-to-outcome）**
中国移动明确把未来网络定义为四要素：**AI Native + Digital Twin + Multi-Agent Collaboration + Computing-Network Integration**。中国电信 CTO 王跃（Yue Wang）则强调 6G 必须是"网络与算力的联合编排"，是**架构级**的转向而非功能级补丁。GSMA 总干事 Vivek Badrinath 把"IQ Era"具象化为机器人、无人机、自动驾驶车的实时协同网络。**三家中国运营商的措辞高度一致**，这不是巧合，而是工信部统一授意下的集团军作战——5G 时代中国是"建得多"，6G 时代中国要"建得聪明"。

**芯片/云层面：被夹在中间的 Nvidia、AWS** 
Zenith 系统 CTO Neeraj Kumar 在 RCR Wireless 的评论一针见血："**管道公司不再 dumb 了**（dumb pipes no more）"。95% 的组织说主权 AI 重要，只有 29% 真的在做——这个 gap 正是运营商的机会窗口。但反过来看，AWS+Nokia+Databricks 的"telco AI 控制层"联盟、MCP/A2A 协议让 AI 智能体直接调用运营商 API（Telefónica 已试点反欺诈场景），说明**超大规模云厂商正在反向渗透运营商的 API 经济**。**运营商要么成为 Agent 经济的流量入口，要么被绕过，没有中间地带**。

### 3. 技术/商业含义

**技术含义**：
- **网络架构的"算网一体"原生化**：6G 不再是 5G 的速率升级，而是把 AI 推理算力（特别是 token 生成）作为一等公民嵌入基站、核心网、传输网。中国电信明确说这是"fundamental architectural shift"，不是 feature add-on。
- **上行带宽成为新瓶颈**：Token 经济对上行需求激增（用户上传 prompt、数据、上下文），华为把"5G-A 高上行"放在解决方案第一位，是真需求，不是 PPT 概念。
- **Token 计量开启新的商业模式**：从"包月不限量"走向"按 Token/按体验"计费，类似云算力的 spot instance 模型。商业逻辑从"卖带宽"变成"卖智能体调用次数+质量保证"。

**商业含义**：
- **2.1 万亿美元盘子**：GSMA 预测中国移动产业 2030 年贡献 GDP 2.1 万亿美元（2025 年 1.5 万亿），这其中 AI 相关业务（机器人、车、低空经济）是增量主战场。
- **5G-A 用户突破 1000 万**：中国 330+ 城市已覆盖，这是 5G-A 商业化的关键拐点。1000 万是"概念验证"到"规模盈利"的分水岭。
- **设备商竞争维度迁移**：单纯比 RAN 性能、价格的旧游戏结束，新游戏比的是"AI 算力调度+Token 货币化平台+生态绑定"。华为靠"三家运营商联合发布"抢叙事主导权；Ericsson 靠"主权 AI + 测试中心"在欧洲抢差异化；**Nokia 走第三条路——AWS/Databricks 联盟路线**。

### 4. 对从业者的启示

**通信工程师（架构/规划方向）**：
- **立刻补两个技能**：AI 推理工作负载的网络建模（不是带宽规划，是 token throughput 规划）、算力调度（Kubernetes+RDMA 在电信场景的落地）。MWC 上所有 CTO 都在谈"网络+算力联合编排"，未来 18 个月内这部分会成为内部晋升的核心能力。
- **关注上行**：5G-A 高上行是真正落地的方向，如果你负责规划，多花时间研究 TDD 配比调整、上行增强（3U1D、SUL 频谱）的实际部署案例，不要等厂家来推。

**解决方案/产品经理**：
- **不要再做大网连接方案了**。客户（行业用户）要的是"算力+连接+AI 应用"端到端方案，纯连接方案的天花板已经被压到 ARPU 几块钱的级别。
- **抓 Token 货币化的第一个案例**：找 1-2 个愿意试点的行业客户（机器人、低空、自动驾驶优先），从"按连接计费"转到"按 AI 调用计费"，哪怕只是内部 POC，也是占位。

**战略/市场分析人员**：
- **盯紧三个数据点**：①华为/中兴运营商业务的 Token 相关收入占比变化（季报披露）；②中国电信/移动的智算业务（IDC+云+AI 推理）收入增速；③Open Gateway API 的调用量（GSMA 季度发布）。
- **风险提示**：如果智能体经济跑得比运营商快（比如 OpenAI/Google 直接绕过运营商拉专用网络），"Token 货币化"叙事会变成设备商单方面的话术。要持续跟踪 MCP/A2A 协议的生态扩张速度。

**给所有从业者的一句话**：**通信业的下一个十年，比的不是"覆盖多广"，而是"懂不懂 AI 负载"。** 从今天起，假装 AI 不存在的工作方式已经过期。

## 简讯

**① China Telecom 明确 6G 架构级转向：网络+算力联合编排**
中国电信首席技术官王跃在 RCR Wireless 撰文，AI-native 6G 需要"fundamental architectural shift"，把网络资源和算力资源做联合编排，不是 5G 的功能补丁。**为什么重要**：这是中国主流运营商第一次用"架构级"措辞描述 6G，意味着 6G 标准讨论中"算力内生"很可能成为必选项而非可选项。直接影响未来 3GPP Release 21/22 的中国提案方向。（来源：RCR Wireless, 6/25）

**② 中国 5G-A 用户突破 1000 万，覆盖 330+ 城市**
MWC Shanghai 开幕主旨演讲披露：中国 5G-A 商用进入规模阶段，用户数突破 1000 万，覆盖城市从一线扩展到 330+ 个。**为什么重要**：1000 万是 5G-A 从"概念验证"到"规模盈利"的临界点，意味着设备商可以开始讲 ROI 故事，运营商可以开始推 5G-A 专属套餐。下一波增长来自 5G-A + AI 终端（如 AI 手机、AI 眼镜）的捆绑销售。（来源：RCR Wireless, 6/24）

**③ Ericsson+Telia 在瑞典投 3 亿克朗建 5G/6G/AI 国家测试中心"Digital Arena Sweden"**
Ericsson 主导，Telia 落地，瑞典创新署 Vinnova 资助，RISE 研究院、KTH 皇家理工学院参与。**为什么重要**：欧洲在 6G 上选择"主权 AI+测试床"路线，和中国"规模商用+运营商主导"路线形成对照。Ericsson 用 2900 万美元锁定瑞典本土 6G 试点权，意在把欧洲规制优势（数据主权）转化为商业优势，反击华为在欧洲的市场攻势。（来源：Computer Weekly / Ericsson 官方, 6/25）

**④ RCR Wireless 评论："Dumb pipes 时代终结，运营商有十年一遇的 AI 机会"**
Zenith 系统 CTO Neeraj Kumar 长文论述：超大规模云厂商（Microsoft、Google）正在向电信价值链渗透，但**主权 AI、合规 AI、私有 AI 三个需求缺口**给了运营商独特窗口。同时警告：MCP/A2A 协议下，AI 智能体可以绕过运营商直接调用网络 API，运营商要么在 Agent 经济里、要么被绕过。**为什么重要**：这篇评论把"AI 时代运营商价值"从口号变成了具体的三个数字（95% 想主权 AI、29% 做了、NTT Data 2026 数据）和两个协议（MCP、A2A），是给全行业战略部门的一份清醒提醒。（来源：RCR Wireless, 6/23）

## 信号追踪（供周报汇总）

### 信号 1：Token 货币化从概念走向方案包

- **信号内容**：华为联合三大运营商在 MWC Shanghai 发布"Token 货币化"解决方案包；David Wang 把它列入"AICentric 目标网络"四大方案之一。同期中国移动 EVP 提出"bits + tokens delivery"的网络定位转变。
- **为什么值得追踪**：这是通信业 30 年来第一次提出"按智能体调用计费"的新计量单位。如果中国三家运营商在 2026 H2 推出第一个商用 Token 计费套餐，将成为全球电信商业模式转折点。
- **追踪窗口**：2026 Q3-Q4（关注中国电信/移动季报中"AI 业务收入"披露、华为合作伙伴大会是否有新方案升级）
- **跟踪指标**：①中国运营商 Token/API 相关业务收入披露；②华为运营商 BG 的 Token 方案合同数；③GSMA Open Gateway API 调用量季度报告

### 信号 2：6G 标准讨论中"算力内生"成中国共识

- **信号内容**：中国电信 CTO 公开称 AI-native 6G 是"架构级"转向；中国移动提出"AI Native + 算网一体"四要素架构；工信部总工程师在 MWC Shanghai 表态"加速推进下一代数字基础设施同时推进 6G 研究"。
- **为什么值得追踪**：中国在 5G 时代是"建得多"，6G 时代正在抢先定义"AI 原生网络"的国际标准。如果"算力内生"被写入 3GPP Release 21，将影响全球设备商的研发路线图。
- **追踪窗口**：2026 H2 - 2027 H1（3GPP Release 20 收尾、Release 21 启动讨论期）
- **跟踪指标**：①3GPP SA1/SA2 中国运营商的 6G 提案数量与采纳率；②IMT-2030 推进组的白皮书更新；③中国 6G 试验网（3.5GHz/4.9GHz）的部署进展

### 信号 3：主权 AI 算力成欧洲电信差异化战略

- **信号内容**：Ericsson+Telia 瑞典测试中心（3 亿克朗）锁定"主权 AI"叙事；Zenith CTO 评论称 95% 组织要主权 AI、仅 29% 落地是运营商机会；Broadcom VMware Telco Cloud 9 主打私有 AI as-a-service。
- **为什么值得追踪**：欧洲在 5G 时代被中美甩开差距，6G 时代选择"规则+主权"路线做差异化。这会催生新的电信云市场（主权云、合规 AI 推理），对中国设备商出海形成新壁垒。
- **追踪窗口**：2026 Q3 - 2027 Q2（欧盟 AI Act 实施细则落地、欧盟 6G 旗舰项目 Hexa-X-III 启动）
- **跟踪指标**：①欧洲电信运营商私有 AI 云业务披露（Deutsche Telekom、Orange、Telefónica）；②欧盟"AI 工厂"（AI Factory）网络中的电信节点数量；③华为/中兴在欧洲的市场份额变化（季度跟踪）

## 编辑后记

**本周通信业的最大主线只有一个**：从 MWC Shanghai 到 RCR Wireless 评论到 Ericsson 瑞典测试中心，全行业在 6 月 22-25 日这周内**集体宣告**了同一个范式——"通信网络 = 智能体承载网"。这个共识的密度和速度，是 5G 时代没有过的。

下周值得关注：MWC Shanghai 后续报道会陆续出炉（华为白皮书、各运营商展台细节）；同时关注 7 月初的 3GPP TSG SA 会议，看 6G 早期需求文档是否呼应"算力内生"。

**判断**：通信业的"AI 叙事"已经从 PPT 概念进入了"方案包+试点测试中心+商业模式"三件套落地阶段。从业者如果 2026 H2 还在按"卖连接"思维做规划，2027 年会很被动。
