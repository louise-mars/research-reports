# 通信行业日报 | 2026-06-27（周六）

> 编者按：MWC 上海 2026 释放的"AI-native 网络 + IQ Era"信号,正在重写运营商、设备商、芯片商的角色边界。今日焦点聚焦于此。

---

## 🎯 今日焦点：MWC 上海 2026 落幕,中国电信+中国移动联手定义"AI-native 6G",运营商从"管道"走向"算力编排者"

### 1. 事件概述

MWC 上海 2026 于本周(6/24-26)落幕,核心信号高度收敛——**中国电信 CTO 王越、中国移动董事长陈忠岳、GSMA 总干事 Vivek Badrinath 在三个不同场合达成同一个判断:6G 必须是 AI-native,网络必须与算力/数据/智能联合编排,运营商的角色从"哑管道"升级为"智能编排层"**。GSMA 同期发布数据:到 2030 年,中国移动产业将为国民经济贡献 2.1 万亿美元。

### 2. 行业格局影响

**运营商位置移动**:中国电信首次明确提出"通算存智"五要素可编排化(王越原话:"when the network can seamlessly expose and orchestrate the communication, compute, data, intelligence, and assurance as the capabilities to our customers"),这意味着运营商不再卖带宽,卖的是"AI 能力 API"。中国移动陈忠岳同步表态"让移动+AI 更普惠",把 agentic AI 推到机器人/无人机/自动驾驶场景。中国联通此前与电信的共建共享延伸到了"资源编排"层面。

**设备商位置移动**:华为在 MWC 上海呼吁"token 货币化"(把 AI 推理 token 当成网络商品卖),这是把 AI 算力变成网络 KPI 的尝试——设备商如果跟不上"AI-native 网络"的定义权,就只剩做盒子的命运。Ericsson 的反应是联合 Telia 在瑞典投 3100 万美元建 5G/6G/AI 测试中心 Digital Arena Sweden,与 Lund 大学、KTH 合作,押注"端到端 6G+AI 试验场"。

**芯片商位置移动**:这是今天没有明说但值得盯住的变化——AI-native 6G 的核心是"网络+算力联合编排",这意味着网络芯片(传统 NPU/DPU)与 AI 加速器(GPU/NPU)的边界开始模糊。NVIDIA State of AI in Telecom 2026、JPMorgan AI Infrastructure Outlook 都在讲同一件事:未来 5 年,网络设备的 BOM 里 AI 芯片占比会从今天的 5-10% 飙升到 30%+。

**竞争态势**:中国三家运营商"联合定义标准 + 联合建网"的打法(电信+联通 5G 共建共享,现在延伸到 AI-native 6G 资源编排),对 Ericsson/Nokia 的传统"卖给每家一张独立网"模式构成根本挑战。Ericsson 的应对是"绑定运营商做前沿试验场",Nokia 的路径是绑定 AWS+Databricks 做"AI 控制层"——两条路都在试图避免被边缘化。

### 3. 技术/商业含义

**技术含义**:
- **架构层**:从 5G 的"确定性 + 预定义接口"转向 6G 的"AI 动态编排"。王越的核心论点是"今天的网络是为确定性设计的,6G 必须为不确定性(AI 推理负载)设计"。
- **频谱层**:MWC 上海明确呼吁推动 U6GHz 频谱落地,这是 6G 容量层的关键拼图。
- **空天一体**:NTN(非地面网络)的产业化被三家运营商同时提及,卫星+地面融合进入商用倒计时。
- **网络 API 化**:GSMA Open Gateway 已覆盖 86 家运营商集团、300+ 网络、80% 全球移动连接。Telefónica+Nokia 已经在做"AI agent 直接调网络 API 阻断银行欺诈"的 PoC。

**商业含义**:
- 运营商的 ARPU 模型从"按流量计费"→"按 token/能力调用计费"切换。华为的"token 货币化"不是口号,是商业模式重构。
- 设备商的护城河从"硬件性能"→"AI-native 软件栈 + 生态绑定"迁移。Ericsson 投 3100 万美元做试验场,本质是买"未来标准的定义席位"。
- 网络 API 市场(Gartner 预测 2028 年规模超 100 亿美元)将成为运营商与超大规模云(微软/谷歌/AWS)正面竞争的战场——超大规模云的优势在模型,运营商的优势在网络能力 API。

### 4. 对从业者的启示(具体可执行)

**给运营商/网络规划岗**:
- **立即动作**:盘点现网中"可以被编排的能力"(带宽、QoS、位置、SIM swap、QoD),对照 GSMA Open Gateway 31 个标准 API 看自家开了多少。落后于平均(20+ 个)就要立项追赶。
- **3 个月内**:在 5G-A 现网里选 1-2 个高价值场景(高密度活动/工业园区/车联网),做"场景化资源编排"PoC。中国电信+ZTE 的 AI 驱动资源分配是现成参考案例。
- **避免的坑**:不要把"AI-native"做成 PPT 词汇。要在 O/BSS 层面有真实改造——AI agent 要能调你的网络 API,你才不会被 agent 经济绕过。

**给设备商/产品经理**:
- **核心判断**:未来 3 年的产品路线图必须回答"我们的 AI-native 软件栈能不能让运营商把我们的设备纳入 agent 编排"。如果答案是"不能",就要么被替换,要么降级成白盒供应商。
- **跟进的标的**:Ericsson+Telia 的 Digital Arena Sweden(瑞典 5G/6G/AI 试验场)是一个值得持续跟进的样板——它定义了"设备商+运营商+学术机构"的三方协同模式。
- **警惕**:Huawei 在 MWC 上海把"token 货币化"做成商业口号,意味着它已经看到了运营商 ARPU 切换的窗口期。Nokia 的 AWS+Databricks 联盟是防守反击。

**给做技术选型/采购的从业者**:
- 2026 下半年的设备选型要新增三个维度:**AI 算力配比**(每台 BBU/RU 的 AI 加速器 TOPS)、**API 暴露能力**(支持哪些 GSMA Open Gateway 标准 API)、**Agent 友好度**(能否被 MCP/A2A 协议调用)。
- 给采购的建议:**别再按"纯硬件成本"评标**,要看 TCO 含 AI 软件订阅。Ericsson 的"AI 注入"溢价是否值得,要算 5 年账。

**给个人职业规划**:
- 通信+AI 交叉技能的需求会在 2026 下半年-2027 年爆发式增长。具体可学的栈:**AI agent 框架( LangChain/AutoGen/MCP)**、**网络 API 设计(GSMA Open Gateway 规范)**、**AI-native 网络架构(IETF/3GPP Release 21+)**。
- 通信行业的下一个 5 年高薪岗位不会是"纯 5G 优化工程师",而是"懂网络的 AI 产品经理"和"懂 AI 的网络架构师"。

## 📰 简讯

**1. GSMA:到 2030 年中国移动产业将贡献中国 GDP 2.1 万亿美元**
工信部总工程师张志彤在 MWC 上海开幕演讲中确认,移动产业作为国民经济战略性、基础性、先导性产业的地位进一步强化。具体路径包括"双千兆→双万兆"演进、6G 标准研发加速、AI 与农业/教育/医疗深度融合。**为什么重要**:这是官方口径对通信行业战略地位的再确认,意味着 2026-2030 年的产业政策红利会持续释放,5G-A/6G/AI-native 网络投资有政策兜底。

**2. 华为呼吁"AI-native 网络 + token 货币化",把 AI 推理变成网络商品**
华为在 MWC 上海提出激进命题:未来网络的核心 KPI 不再是带宽/时延,而是"每 token 成本"和"token 推理时延"。**为什么重要**:如果华为推动运营商接受"按 token 计费"模式,会直接重塑运营商 BSS 系统和计费架构。设备商首次尝试定义运营商的商业模式,这比卖盒子利润高得多。

**3. Ericsson+Telia 在瑞典建 3100 万美元 5G/6G/AI 测试中心 Digital Arena Sweden**
联合 Lund 大学、KTH 皇家理工学院,建预商用 6G 测试环境。**为什么重要**:这是 Ericsson 在欧洲"中国式联合建网"压力下的反击——通过绑定学术机构抢 6G 标准定义权。对中国设备商出海的启示:海外不能再单卖设备,要考虑"设备+试验场+标准"的捆绑打法。

**4. 中国移动 EVP 李慧镝在 DTW 2026 演讲:Autonomous Networks 进入"未来加速"阶段**
李慧镝(中国移动副总经理)阐述中国移动在自治网络(L4-L5)上的路线图,核心是"把 AI 决策嵌到 O/BSS 和网络管理全流程"。**为什么重要**:中国移动是全球最大运营商,其自治网络路线图会被 GSMA/ITU 采纳为参考标准。这对国内厂商(华为/中兴)是利好——他们的自治网络方案有"自家练兵场"。

## 🔍 信号追踪

**信号 1:运营商"AI 能力 API 化"的军备竞赛正在加速**
- **信号内容**:GSMA Open Gateway 86 家运营商、300+ 网络、80% 全球移动连接已加入;Telefónica+Nokia PoC 用 AI agent 直接调网络 API 阻断欺诈;华为推动"token 货币化";中国电信王越提"通算存智五要素可编排"。
- **为什么追踪**:这是运营商未来 5 年最大的商业模式重构机会,也是与超大规模云(微软/谷歌/AWS)正面对决的主战场。落后者会被 agent 经济绕过。
- **追踪窗口期**:2026 Q3-Q4 是关键期,关注 ITU/3GPP/GSMA 的 AI-native 网络标准冻结进度,以及 IMT-2030 推进组的 6G 框架文件。

**信号 2:网络芯片 + AI 芯片的边界开始模糊**
- **信号内容**:AI-native 6G 要求网络设备原生嵌入 AI 推理能力;NVIDIA 推出电信专用 AI 推理方案;Ericsson/华为的高端设备 BOM 中 AI 加速器占比上升。
- **为什么追踪**:这会颠覆传统通信芯片市场格局。Marvell/Broadcom 的网络芯片业务可能面临"NVIDIA/AI ASIC 厂商"的跨界侵蚀。国内紫光展锐/中兴微的 AI 通信融合芯片值得关注。
- **追踪窗口期**:2026 年内关注 MWC 洛杉矶(秋季)是否有重磅 AI 通信芯片发布;2027 年初的 CES 会有端侧 AI + 网络融合的早期产品。

**信号 3:设备商从"卖盒子"到"卖试验场+标准席位"的商业模式升级**
- **信号内容**:Ericsson+Telia+瑞典政府 3100 万美元建 Digital Arena Sweden;华为在 MWC 上海把"token 货币化"做成商业倡议;Nokia 绑定 AWS+Databricks。
- **为什么追踪**:设备商的护城河从硬件迁移到软件+生态,这对中国设备商(华为/中兴)的国际化路径有结构性影响——单纯打价格战的时代结束了。
- **追踪窗口期**:2026 H2 重点跟踪 Huawei/Ericsson/Nokia 在海外的"联合试验场"动作,以及 ITU IMT-2030 的标准贡献榜。
