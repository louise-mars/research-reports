# 通信行业日报 · 2026-06-28（周日）

> 今日核心：MWC Shanghai 2026 把通信行业的未来十年钉在了"AI-native 网络 + Token 计费"两根钉子上。中国三大运营商 + 华为 + GSMA 集体发声，海外爱立信/电信运营商则以 6G 测试中心反击。本日报梳理格局变化与从业启示。

---

## 一、今日焦点：MWC Shanghai 2026 开幕，通信业集体押注"AI-native + Token 货币化"

### 事件概述
6月24日 MWC Shanghai 2026 开幕，GSMA 携中国电信、中国移动、中国联通、华为集体打出"IQ era"（智能体时代）叙事——AI-native 6G 必须打破"哑管道"宿命，未来网络要走向"通信+计算+存储+AI 资源联合编排"，并按 token 流量而非 bit 流量收费。GSMA 当日发布预测：到 2030 年移动通信技术将为中国经济贡献 2.1 万亿美元（2025 年为 1.5 万亿）。

### 行业格局影响
- **运营商**：从"卖比特"转向"卖智能"。中国电信首席技术官王越明确表示 AI-native 6G 必须"通算存 AI 联合编排"，要求组织架构、网络架构同步变革——运营商内部"网络部"和"云/IT 部"边界将被打破。中国移动副总裁李慧镝在 DTW 2026（6月24日前后）抛出"AI Native 网络 + 数字孪生 + 多智能体协同 + 算网融合"四位一体路线，并提出网络从"bit transmission"演进到"bits + tokens delivery"。
- **设备商**：华为在 MWC Shanghai 主推"服务-网络-算力"三位一体与 token 货币化，副董事长汪涛（David Wang）亲自站台"5G-A 高上行 + 体验经营 + token 经营"，把上行带宽重新定义为 AI 时代的稀缺资源。爱立信则牵手 Telia 在瑞典设立 3 亿瑞典克朗（约 3120 万美元）的"Digital Arena Sweden"国家级 5G/6G/AI 测试中心，剑指 6G 早期生态卡位。
- **芯片/算力方**：被倒逼加入战局。中国移动明确"算网融合"是基础设施层，意味着 AI 算力（GPU/NPU）调度将成为运营商核心能力，传统设备商和云厂商（华为云、阿里云、移动云）的边界进一步模糊。

**一句话：MWC Shanghai 2026 标志着"AI native"从概念口号升级为运营商、设备商共同背书的架构共识，2026 是落地分水岭。**

### 技术与商业含义
- **技术含义**：6G 标准方向被锁定在"通算一体"——单谈空口速率已经没有意义，AI 任务调度、Token 路由、计算感知（compute-aware）QoS、低时延算力网络将成为新 KPI。中国电信明确点名"physical AI 与机器人"将驱动低时延算力感知 6G 需求。
- **商业含义**：运营商商业模式将从按流量包月转向"按 token 计量 + 体验经营 + 网络 API 调用"三件套。GSMA Open Gateway 已在 86 家运营商集团、300+ 网络落地，60% 的企业客户预计 2026 年底部署网络驱动 AI 解决方案。这意味着电信业终于有了一张与超大规模云厂商（Hypedcaler）抢蛋糕的牌——网络不再只是管道，而是"可编程的智能体基础设施"。

### 对从业者的启示（具体可执行）
1. **如果你在运营商网络规划/优化部门**：今年下半年开始，把"算力感知调度""AI 任务时延预算"列入 KPI 跟踪项，不能只盯着空口 KPI。可以主动申请加入公司内部的"算网融合"或"AI Native"专项小组，否则 2027 年组织调整时会被边缘化。
2. **如果你在设备商或集成商**：华为已经定义了 token 货币化的叙事，爱立信押注 6G 测试，中国厂商的机会窗口是"在 5G-A 高上行 + 体验经营"上抢落地案例。北欧阵营（爱立信、诺基亚）的 6G 动作值得追踪，但短期商业回报仍在 5G-A。
3. **如果你在做产品/解决方案**：客户对话里加一个问题："你们打算怎么用网络 API 帮 AI agent 做风控/SIM 验证？"——Telefónica 和诺基亚已经在和银行客户做 agent 直连网络 API 的试点，这会是 2026 下半年 ToB 增长点。
4. **战略层面**：MWC Shanghai 的信号非常明确——2026 是"从 5G-A 走向 AI-native 6G"的过渡年。如果你的产品/技术路线图里没有"通算一体"和"token 计费"两条线，年底前必须补上。

## 二、简讯

### 1. GSMA 发布"2030 中国移动经济报告"：移动技术 2030 年贡献 2.1 万亿美元
6月24日 MWC Shanghai 开幕主旨演讲，工信部总工程师钟志红、GSMA 总干事 Vivek Badrinath 共同发布。中国 5G-A 已覆盖 330+ 城市，用户数突破 1000 万；AI 驱动的场景化网络管理正在快速铺开。**为何重要**：这是 GSMA 给"AI-native"背书的官方数据锚点，未来 5 年中国通信产业链的总盘子和政策延续性都看这一数字。

### 2. 华为联合中国三大运营商发布 5G-A 高上行 + Token 货币化系列方案
华为副董事长汪涛主旨演讲定调：高上行是 token 时代基础设施关键能力。中国移动、中国电信、中国联通均参与发布。**为何重要**：这是华为把"上行带宽"从技术参数重新定义为商业资源——AI agent、具身智能、机器人交互都需要上行突破，对光模块、RAN、传输网提出明确升级方向。

### 3. 爱立信 + Telia 在瑞典启动"Digital Arena Sweden"国家级 5G/6G/AI 测试中心
总投资 3 亿瑞典克朗（约 3120 万美元），瑞典创新署 Vinnova 注资，RISE、KTH 皇家理工学院参与。在 Almedalen 政治论坛期间启动，定位为北欧版 6G 早期生态实验场。**为何重要**：北欧阵营在 6G 标准化窗口期（2026-2028）抢先建设生态壁垒，与中国"通算一体"形成两种 6G 路线竞争，标准分裂风险上升。

### 4. NSW 州政府再投 2.09 亿澳元升级 P25 应急通信网
澳大利亚新南威尔士州政府承诺未来 10 年追加 2.09 亿澳元用于警方/消防/救护的 P25 数字集群。**为何重要**：在 5G/6G 喧闹中，专网与关键任务通信（PMR/MCX）的稳健现金流被低估；专网运营商和窄带集群厂商仍有政策驱动的长尾机会。

## 三、信号追踪（供周报汇总）

### 🔍 信号 1：Token 货币化从概念走向运营商 KPI
- **内容**：MWC Shanghai 2026 上华为与中国三大运营商联合发布"5G-A 高上行 + 体验经营 + token 货币化"系列方案，中国移动李慧镝在 DTW 2026 明确网络要从"bit transmission"演进为"bits + tokens delivery"。
- **为何值得追踪**：这是运营商第一次集体背书"按 token 计费"作为新商业模型。如果 2026 H2 出现试点计费案例（特别是针对 AI agent、机器人交互场景），整个 ToB 价值链（设备、光模块、BSS/OSS、计费平台）会被重估。
- **追踪窗口期**：2026 Q3 - 2027 Q1（重点关注 9 月华为全联接大会、巴塞罗那 MWC 2027 上的进度披露）。

### 🔍 信号 2：6G 标准出现"中国-北欧"双路线竞争苗头
- **内容**：中国阵营（电信、移动、华为）主推"通算一体 + AI-native"；北欧阵营（爱立信 + Telia + 芬兰 Oulu 大学、KTH）通过国家级测试中心抢 6G 早期生态。爱立信 Digital Arena Sweden 与芬兰 6G resilience programme 形成北欧联合阵线。
- **为何值得追踪**：3GPP Release 21/22 标准化窗口期（2026-2028），两种路线的标准争夺会直接影响空口、网络架构、AI 接口的全球统一性。中国厂商需提前评估专利布局和供应链适配。
- **追踪窗口期**：2026 Q3 - 2028 H1（关注 3GPP 会议、ITU-R IMT-2030 框架文件、北欧后续测试中心扩员动作）。

### 🔍 信号 3：AI Agent 直连网络 API（GSMA Open Gateway + MCP/A2A 协议）
- **内容**：RCR Wireless 评论指出，2026 年是 agentic networks 的拐点。Telefónica + 诺基亚已试点 AI agent 通过 Model Context Protocol（MCP）和 Agent-to-Agent（A2A）协议直接调用 SIM-swap、device-swap 等网络 API 做实时反欺诈，无需人工介入。GSMA 在 MWC 2026 巴塞罗那已警告："如果网络 API 不支持 MCP，AI agent 会绕过运营商"。
- **为何值得追踪**：这是运营商从"哑管道"翻身最关键的商业模式试金石。如果 MCP/A2A 标准成熟，运营商将首次获得与超大规模云厂商在 AI 价值链中的对等位置。
- **追踪窗口期**：2026 H2 - 2027 H1（关注 GSMA Open Gateway 扩员、新增 API 类型、企业级 MCP 网关产品落地）。
