## 今日焦点：China Telecom王越提出"AI-native 6G网算一体编排"——架构级宣言

### 1. 事件概述
6月25日，China Telecom首席技术专家王越（Yue Wang）在RCR Tech Telco AI Forum上明确表态：**AI-native 6G必须实现"通信、计算、存储、AI资源"的联合编排（joint orchestration）**。她直言，当前电信网络基于确定性架构、预定义接口和规则引擎设计，"无法支撑未来AI服务"。这是MWC Shanghai 2026期间（6月24-26日）三家中国运营商高层发出的最具体、最有架构感的6G路线信号。

### 2. 行业格局影响
- **运营商位置移动**：中国电信从"5G+云"二元叙事，正式升级为"网+算+智"三元叙事。这意味着运营商不再只卖连接，而是要把"算力调度"作为第一类核心产品对外卖。
- **设备商压力**：如果网算编排主导权在运营商手里，Ericsson、Nokia的传统基站+核心网栈会被边缘化。华为/中兴的"网+云+AI"全栈方案反而更对位——这是China Telecom + ZTE在5G-A阶段已经在做的AI驱动资源分配。
- **芯片商新变量**：网算一体意味着RAN侧会大量部署推理芯片（NVIDIA Aerial、华为昇腾、寒武纪），博通/Marvell传统SoC路径面临重估。
- **云厂商**（AWS/Azure/GCP）原本想做"运营商之上的一层"，现在被运营商反向挤压——运营商要把算力"留在网内"。

### 3. 技术/商业含义
- **技术**：从"best-effort连接"到"intent-to-outcome"（中国移动李慧迪的同款表述）。网络开始理解需求、参与决策、创造价值。Digital Twin + Multi-Agent + 网算一体是三个可落地的技术抓手。
- **商业**：每GB连接的ARPU持续下行，运营商必须找到"价值锚"——AI算力分发和场景化编排就是新锚点。McKinsey 12月2025对49位Telco CxO的调研显示，AI投资尚未转化为结构性价值，**问题不在技术，在运营模式**。

### 4. 对从业者的启示（具体可执行）
1. **重新定位你的技能树**：如果你还在做传统无线参数优化，6-12个月内会被自动化。要主动学**意图驱动网络（intent-based networking）、RAG over网络知识库、Agent编排框架（LangGraph/AutoGen）**。这些是从"操作工"到"网络智能体设计师"的门票。
2. **关注U6GHz频段**：MWC Shanghai上Wang Tao（华为轮值董事长）明确呼吁推动U6GHz频谱。这条频段中美的博弈将决定6G设备成本曲线——做设备规划的人要开始建U6GHz仿真能力。
3. **在内部推动"场景化SLA"**：传统SLA是带宽/时延/可用性三件套。AI-native网络要把"推理算力"、"模型位置"、"Token成本"纳入SLA。**这是你向领导汇报时能直接用的语言**——把公司的话术从"卖连接"改成"卖AI可获得性"。
4. **盯住两个窗口**：① Ericsson 6月Mobility Report已经预测AI流量2031是2025的3倍（上行），这个3倍不是"全网均值"，是边缘侧集中爆发；② 6G标准化时间表（ITU 2030前后冻结）——从现在到2028年是"Pre-6G"黄金窗口，先行者定义规则。

## 简讯

**① 华为呼吁AI-native网络和"Token货币化"**
MWC Shanghai 2026上，华为轮值董事长汪涛提出将AI Token作为新型计费单位——按推理调用次数/算力消耗收费，而非按流量计费。**为什么重要**：这是设备商第一次公开挑战运营商的"流量计费"商业模式。如果Token计费落地，运营商的BSS/OSS需要重构，计费系统供应商（Amdocs、华为计费）面临5年内最大一次架构重写。

**② China Mobile李慧迪发布"AI Native + Digital Twin + Multi-Agent + 网算一体"四层架构**
中国移动EVP在DTW 2026（Digital Transformation World）首次把自主网络（AN）路线图讲到"四层协同"粒度，并明确说"网络将不再传输比特，而是理解需求、协调决策、创造价值"。**为什么重要**：这是中国最大运营商第一次把"网络价值锚"从"连接"切到"决策"，对内部组织意味着CT/BSS/OSS团队需要重组。

**③ Ericsson 6月Mobility Report：5G已承载48%移动流量，2031年AI流量是2025年3倍**
5G渗透率进入加速段，全球85%移动流量将在2031年跑在5G上。AI驱动的上行流量（视频/传感器/具身智能）是增长主因。**为什么重要**：这是"5G杀手级应用"的正式回答——不是to C视频，是to B AI。运营商的5G投资回收模型需要重写。

**④ 瑞典Ericsson + Telia共建5G/6G/AI测试中心**
Ericsson与Telia宣布在瑞典建6G测试床，聚焦AI-RAN集成。**为什么重要**：欧洲在6G上选了"AI-RAN"作为差异化路线（与中国"网算一体"路线并行）。两条路线最终会在3GPP/ITU标准上正面碰撞，影响全球设备供应链分工。

## 信号追踪

### 信号1：6G路线分歧——"网算一体" vs "AI-RAN"
- **信号内容**：中国三大运营商押注"网算编排主导权留在运营商"，欧洲Ericsson/Telia押注"AI下沉到RAN"。两条路线对设备供应链、芯片架构、OSS架构影响完全不同。
- **为什么追踪**：6G标准2028-2030冻结前，这是定义设备形态的窗口期。中美欧三方博弈结果会决定2027-2030年的设备招标话语权。
- **追踪窗口期**：6-18个月。关键节点：3GPP Release 21（预计2027 Q3）、ITU IMT-2030框架最终版（2027年底）、MWC 2027/2028。

### 信号2：Token经济 vs 流量经济
- **信号内容**：华为、GSMA、部分欧美分析师开始讨论"按AI推理调用计费"。这是对"按流量计费"商业模式的根本挑战。
- **为什么追踪**：商业模式变化会引发BSS/OSS、计费、合规（AI服务监管）的连锁重构。运营商的5G投资回收模型取决于此。
- **追踪窗口期**：12-24个月。关键节点：GSMA Open Gateway Token计费API（2026 Q4测试）、TM Forum Catalysts项目（季度更新）、中国电信/移动的AI服务商用套餐发布。

### 信号3：AI-native 6G + 具身智能（机器人/无人机/自动驾驶）
- **信号内容**：GSMA总干事Badrinath在MWC Shanghai确认"中国运营商已在用移动网络支撑人形机器人、低空经济（无人机）、自动驾驶"。这不再是PPT。
- **为什么追踪**：具身智能是6G"杀手级应用"的真实候选。运营商能否切入这个市场决定未来10年增长曲线。
- **追踪窗口期**：6-12个月。关键节点：工信部低空经济频谱分配（2026 Q3-Q4）、中国电信"机器人SLA"商用试点、特斯拉Optimus/国内人形机器人公司的网络需求白皮书。
