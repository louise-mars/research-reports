# 通信行业日报 · 2026-10-06

> 今日核心判断：中国移动5G集采规模再次大幅缩水（从近40万站缩减至26万站，缩水近40%），叠加运营商"三业并举"（通信+算力+智能）的战略转向，5G红利期已正式结束，行业进入"5G-A精耕+AI算力开荒"的双轨新阶段。

## 一、今日焦点：中国移动5G集采缩水近40%，5G建设红利期正式结束

### 1. 事件概述

C114于6月22日报道，中国移动2026-2027年5G无线主设备（700MHz + 2.6GHz/4.9GHz）集采中标候选人公布，华为、中兴、中信科移动、爱立信、诺基亚五家中标。据业内人士透露，本次集采规模约**26万站**，较2025-2026年的近40万站**缩减近40%**——这是继2022年5G建设峰值之后，缩水幅度最大的一轮集采。中国移动2026年总资本开支1366亿元中，5G所在的"通信网络"仅占792亿元（58%），而算力网络378亿元（28%）、智能网络89亿元（6.5%）合计已占34.5%。

### 2. 行业格局影响：设备商"存量博弈"，运营商"角色换轨"

**设备商层面：**
- **华为、中兴双寡头格局进一步固化**：在五家中标企业中，三家中国厂商（华为、中兴、中信科移动）+两家欧洲厂商（爱立信、诺基亚），新厂商零进入。中信科移动作为"国资新军"占据重要位置，国产化比例进一步提升。
- **诺基亚通过"合资"模式保住中国市场份额**：本次集采出现"福建福诺"这一新面孔——这是福建移动与诺基亚1998年就成立的合资公司。诺基亚通过"外资设备主体+本土属地服务"的合资联合体模式进入中标名单，是外资设备商在中国市场"本土化求生"的标志性事件。可以预见，**爱立信大概率会效仿诺基亚模式**，未来中国5G/5G-A市场可能形成"华为中兴+合资欧洲军"的三方格局。
- **Open RAN彻底出局**：本次集采仍采用传统架构，Open RAN厂商无一中标。结合Light Reading 2025年度复盘"Mavenir CEO警告Ericsson和Nokia双寡头、open RAN停滞"——Open RAN在中国的运营商主战场已基本被判死刑。

**运营商层面：**
- **角色换轨**：中国移动已明确将"通信服务、算力服务、智能服务"列为三大主业。这意味着电信运营商的KPI体系正在从"基站数/用户数"切换到"Token吞吐量/算力服务收入/AI应用渗透率"。
- **业务天平倾斜**：算力+智能资本开支合计467亿元，已超过传统通信网络的60%。运营商本质正在从"管道商"演变为"算力+智能服务商"。

### 3. 技术/商业含义

**技术含义：**
- 5G宏站建设进入**存量优化期**：5G-A（5G-Advanced）成为新投资重点——三载波聚合、RedCap、网络智能化是三大技术方向。"5G-A精耕"意味着无线接入网的投资逻辑从"覆盖"转向"场景化"。
- 算力网络（378亿元）和智能网络（89亿元）成为新增长极。中国移动已经把超277万5G基站视为"已有资产"，未来增量看算力。
- 无线主设备的"AI Native"化加速：MWC 2026上Qualcomm的John Smee明确指出6G被设计为**AI-Native Network**——这意味着无线设备本身将内置AI推理能力（类似RAN侧的"小模型"部署），设备商的技术栈正在重构。

**商业含义：**
- **设备商收入结构剧变**：纯5G设备收入下行是趋势，设备商必须找到"算力设备/AI设备"的新收入来源，否则营收将面临系统性下行。
- **运营商估值模型重写**：传统电信运营商的估值锚是ARPU和基站规模，未来要加上"算力服务收入"和"AI解决方案收入"两条曲线。
- **国产替代叙事进入"深水区**：5G主设备国产化已基本完成，下一阶段是"AI算力国产化"（华为昇腾、超聚变等）和"光网络/光模块国产化"。

### 4. 对从业者的启示

对一位通信行业从业者而言，这轮集采的启示是**非常具体和可执行的**：

1. **不要再把"5G基站规模"作为评估行业景气的核心指标**。从2026年开始，应该跟踪的指标是：
   - 5G-A三载波聚合部署进度（看中国移动/电信/联通招标公告）
   - 算力网络资本开支占比（每季度看财报）
   - 智能网络/AI相关招标规模（中国移动"AI+DICT"项目）
   - RedCap模组价格走势（决定行业应用爆发时点）

2. **技能栈升级清单**（2026-2027年必须补齐的能力）：
   - **网络AI化**：AI-RAN、AI-RIC、意图驱动网络——Open RAN虽然在中国受阻，但AI-RAN是共识
   - **算力网络**：算力调度、算力路由（如中国移动的"算网大脑"）
   - **5G-A增强**：三载波聚合、确定性网络、通感一体——这些是5G-A阶段的核心技术
   - **光网络**：FTTR（光纤到房间）是中国移动重点推的方向，9900万千兆用户中11%已部署FTTR

3. **职业路径重新规划**：
   - 如果在**设备商**：考虑从传统无线产品线转向AI算力产品线或光网络产品线——这是少数仍有增量的赛道
   - 如果在**运营商**：从"网络规划/优化"转向"算力服务运营"或"AI解决方案销售"——这两块业务有新的晋升通道
   - 如果在**集成商/乙方**：从"5G项目交付"转向"AI+行业解决方案"（如AI+矿山、AI+港口）——5G项目红利已过

4. **投资视角**：把"5G概念股"重新分类——
   - **存量价值**：纯5G主设备商估值压制难反转
   - **增量价值**：算力服务器、光模块、FTTR、RedCap模组、AI-RAN解决方案商

**一句话总结**：5G建设的高峰已过，行业正从"建网"转向"用网+算网+智网"。**今天的5G集采缩水不是坏消息，而是行业进入成熟期的正常信号——真正的不确定性和机会，都在"5G之后"。**

## 二、简讯（4条）

**1. 中国电信MWC 2026斩获四项GSMA大奖，AI网络创新项目成标杆**
中国电信联合华为打造的"Mobile Network for Thriving AI"项目获GSMA Foundry卓越奖，联合中兴的5G-A项目获Innovation GLOMO奖。**为何重要**：这是运营商与设备商"联合创新"模式的国际化背书，"AI Native Network"已成为中国通信业的对外名片，预计2027年MWC会看到更多此类联合项目。

**2. Open RAN 2025年遇多重打击，挑战者未能撼动五大厂商格局**
Omdia和Dell'Oro数据显示，Mavenir等Open RAN挑战者未能从Ericsson、Nokia、Huawei、ZTE、Samsung五大厂商手中夺取显著市场份额；Mavenir CEO公开承认"open RAN是一场错误的赌注"。**为何重要**：Open RAN作为"去Ericsson化"的西方政治叙事产物，技术上未能证明商业价值。对中国从业者的启示：警惕"政治叙事"驱动的技术路线，可能导致投资失误。

**3. 6G核心网架构分歧加剧，三种方案可能割裂全球标准**
Light Reading披露6G核心网存在三种竞争架构：运营商优先的"演进派"、设备商主导的"革命派"、终端厂商力推的"端智能派"。**为何重要**：6G标准尚未冻结，核心网架构之争已经白热化。对从业者：2027-2028年需密切跟踪3GPP Release 21/22进展，决定未来5-10年的技术路线选择。

**4. NTT Docomo 6G试验实现AI加速吞吐量翻倍**
NTT Docomo在AI赋能的6G试验中将吞吐量翻倍；SKT与三星合作开发6G MIMO和AI-RAN。**为何重要**：亚洲运营商的6G竞赛已经从"标准之争"进入"试验验证"阶段。中国需要警惕的是——NTT和SKT的AI-RAN进展如果率先形成可商用方案，将削弱中国6G标准的国际话语权。

## 三、信号追踪（供周报汇总）

### 信号1：中国运营商"三业并举"战略落地速度

- **信号内容**：中国移动将"通信+算力+智能"列为三大主业，2026年算力+智能资本开支占比已达34.5%（467亿元/1366亿元）。
- **为何值得追踪**：这是电信运营商"估值重估"的起点——如果算力服务收入能在3年内达到通信收入的20%，运营商估值逻辑将系统性切换。
- **追踪窗口期**：2026 Q4 - 2027 Q2（看三大运营商季度财报中"算力服务收入"披露情况）
- **关键指标**：每季度跟踪"算力收入/总收入"占比、"智能解决方案收入"披露口径

### 信号2：诺基亚"合资模式"是否被爱立信效仿

- **信号内容**：诺基亚通过"福建福诺"合资公司保住中国移动集采中标资格。
- **为何值得追踪**：外资设备商在中国5G/5G-A市场的"本土化求生"路径。如果爱立信跟进，可能形成可复制的模式；但如果欧盟出台政策限制这种"技术让渡"，则模式可能受阻。
- **追踪窗口期**：2027年中国电信/联通集采公告（预计2027 Q1-Q2）
- **关键指标**：爱立信是否寻找中国合资伙伴、欧盟是否出台新规

### 信号3：6G核心网三种架构谁将胜出

- **信号内容**：6G核心网存在"演进派vs革命派vs端智能派"三种架构，标准尚未冻结。
- **为何值得追踪**：6G标准将在2028-2029年冻结（3GPP Release 21/22），核心网架构之争将决定未来10年的产业链分工。中国目前推动的是"演进派"（5G-A平滑升级），但NTT Docomo和SKT的AI-RAN进展可能在2027年改变格局。
- **追踪窗口期**：2026 Q4 - 2028 Q4（看3GPP Release 21进展）
- **关键指标**：3GPP会议中国提案占比、NTT/SKT AI-RAN试验成果、Qualcomm/Intel 6G芯片路线图
