# 通信行业日报 | 2026-09-07

---

## 今日焦点：AI-Native 6G 标准框架收官，通信业正式进入"算力即网络"时代

### 1. 事件概述
MWC 2026 期间，ITU 联合 T-Mobile、Ericsson、Nokia 等产业链巨头，完成了 6G 标准第一阶段（IMT-2030 框架）的关键收敛——6G 不再是"更快的5G"，而是把 AI、感知（sensing）、算力（compute）作为一等公民嵌入空口协议。这是从 3GPP Release 18 开始讨论、经历 R19/R20 两轮博弈后，第一次把"AI-Native"写进标准硬性要求。

### 2. 行业格局影响
- **设备商**：Ericsson、Nokia 在 MWC 上率先宣布"AI-RAN 商用路线图"，与高通、Intel 形成 "CPU + 加速器 + RAN" 三层联盟。华为则凭借"Mobile Network for Thriving AI" 提案拿下 GSMA Foundry 卓越奖，宣布其 5.5G AAU 已支持 30 TOPS 端边算力——换言之，**设备商的竞争维度从"射频性能"升级为"算力密度"**。
- **运营商**：中国电信联合华为、中兴拿下四项 GSMA 大奖（含 GLOMO），标志着运营商的护城河从"频谱+基站"转向"AI 业务编排能力"。T-Mobile US 则在北美率先商用 Network API（与 Open Gateway 对齐），运营商开始把自己变成"AI 应用的中间件平台"。
- **芯片商**：高通和 Intel 在 RAN 侧的 x86/ARM 算力之争白热化；Marvell、博通押注"专用 AI 加速 ASIC"。**传统通信芯片厂商面临"边缘 GPU 厂商降维打击"**（Nvidia 已开始推工业级边缘 AI 模块）。

### 3. 技术/商业含义
- **技术含义**：6G 标准第一次承认 RAN 不只是管道，而是分布式 AI 推理节点。这意味着 5G 时代"基站回传业务"的范式彻底失效，**RAN 与 AI 推理引擎的耦合**将成为新 KPI（每瓦特推理 token 数）。
- **商业含义**：
  - **CAPEX 结构巨变**：运营商每新建一张 6G 网络，AI 算力投资将占 35-40%，远超 5G 初期的 10-15%。
  - **新的商业闭环**：运营商可以通过 Network API 把"位置、时延、带宽"卖给出厂价更高的人形机器人、车联网厂商——B2B 收入占比预计 5 年内从 15% 升至 35%。
  - **地缘影响放大**：中国设备商在 AI-Native 6G 上的领先，意味着欧洲"去中国化"政策（德国 2029 年清退华为）将面临"技术代差"压力——爱立信、诺基亚短期内难以补齐端边 AI 算力的短板。

### 4. 对从业者的启示（具体可执行）
1. **技能升级：把"AI+通信"作为下半年主轴**。如果还在做传统 L2/L3 协议开发，本季度内必须开始接触 ONNX/TensorRT 边缘推理框架；目标是 6 个月内能讲清楚"AI-RAN 切片对 KPI 的影响"。
2. **关注 RAN 算力密度指标**：以前优化的是 RSRP、吞吐量、MOS 分数，现在要开始关注 **TOPS/Watt、tokens/Joule**。这会直接影响你做的 feature roadmap。
3. **跳出"基站思维"**：下一次规划网络时，主动拉通云、AI、网三条线；如果团队还没有"AI 业务编排"的角色，建议在 Q4 设立 PoC。
4. **关注 GSMA Open Gateway 和 Network API 商业化**：这决定了未来 3 年运营商能否从"流量管道商"翻身成为"AI 应用平台商"，里面有你升职或跳槽的新赛道。

## 简讯

**① 德国 2029 年前清退华为/中兴 5G 组件——协议进入执行期**
路透社确认德国电信、沃达丰、西班牙电信德国子公司已原则上同意 5 年内替换中国设备。这意味着欧洲 5G "去中国化"从政治口号落地为商业合同。爱立信、诺基亚拿到确定性订单，但交付能力受制于供应链。
**为什么重要**：是中国设备商海外业务的负面信号，但对国产替代（信创）和国内市场份额提升是间接利好——华为/中兴在国内的研发资源会更聚焦。

**② Dell'Oro：海外 5G 核心网收入 Q1 2026 同比再涨，4G Packet Core 增速超大盘**
海外运营商 5G 核心网升级周期远未结束，4G Packet Core 增速意外快于市场均值（受益于 5G NSA 锚点回退需求）。
**为什么重要**：核心网（而非无线侧）是未来 2 年海外业务最确定的增量；如果你做核心网相关产品/方案/海外项目，是好消息。

**③ Ethio Telecom 与华为/爱立信/中兴/诺基亚四大设备商同时签约，开启非洲最大规模 4G+5G 现代化**
埃塞俄比亚电信一次性与四大厂签合作，意味着非洲不再是"单家供应商绑定"模式，而是"分区域多供应商"，对各家交付能力和服务能力提出更高要求。
**为什么重要**：非洲 5G 建设进入"集群式招标"阶段，未来 12 个月可能有更多国家跟进——是中国设备商必须死守的存量市场。

## 信号追踪

### 信号 1：AI-Native 6G 标准硬指标落地
- **内容**：ITU IMT-2030 框架把 AI/sensing/compute 写进 KPI，意味着 6G 设备必须内置推理能力。
- **为何追踪**：这是 10 年一遇的行业范式切换，决定未来 3-5 年所有玩家的位置。
- **追踪窗口**：2026 Q3 ~ 2027 Q2（3GPP R20 冻结 + ITU 频谱分配）。

### 信号 2：Network API 商业化与 GSMA Open Gateway 进展
- **内容**：T-Mobile US、北欧 Telia、欧洲 DT 陆续商用 Network API；中国电信 GSMA 获奖后预计加速跟进。
- **为何追踪**：这是运营商 B2B 转型成败的核心，决定"流量贬值"叙事是否被打破。
- **追踪窗口**：2026 Q3 ~ 2027 Q1（重点看是否有单笔 >$100M 的 API 商业合同披露）。

### 信号 3：欧洲"去中国化"的执行节奏与替代能力缺口
- **内容**：德国 2029 清退时间表确定，但爱立信、诺基亚 AI-RAN 能力暂不及华为。
- **为何追踪**：若欧洲发现"换不掉"，可能引发政策回调或对中国厂商二次开放；若执行坚决，华为/中兴会加速转向亚非拉市场。
- **追踪窗口**：2026 Q4 ~ 2028 Q4（每 6 个月看一次德国/英国/法国实际替换进度）。
